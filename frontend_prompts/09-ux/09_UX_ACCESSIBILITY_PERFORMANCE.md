# PHASE F09 – UX POLISH + ACCESSIBILITY + PERFORMANCE

Đọc toàn bộ frontend implementation trước đó.

Thực hiện một pass UX toàn diện nhưng không đổi business behavior.

DESIGN SYSTEM
- typography
- spacing
- status colors
- tables
- forms
- dialogs
- toasts
- skeletons
- empty states

UX CONSISTENCY
- consistent page header
- breadcrumbs
- filter bars
- action placement
- confirmation patterns
- success/error feedback

ACCESSIBILITY
- keyboard navigation
- focus states
- labels
- aria
- semantic tables/forms
- modal focus management
- contrast

RESPONSIVE
- staff desktop/tablet
- portal mobile-first
- critical workflows usable on smaller screens

PERFORMANCE
- query caching
- pagination
- lazy loading
- code splitting
- avoid N+1 browser requests
- avoid fetching full datasets
- avoid large document previews by default

Error/loading states:
401, 403, 404, validation, server error, empty state.

Validation:
- accessibility checks where tooling available
- performance smoke checks
- all prior tests
- build/typecheck/lint

Checkpoint PHASE_F09.
