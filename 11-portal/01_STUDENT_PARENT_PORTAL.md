# PHASE 11 – STUDENT/PARENT PORTAL

Student can:
- see own profile
- see roadmap
- see own tasks
- see deadlines
- upload allowed docs
- see permitted applications/scholarships/visa
- interact where explicitly permitted

Parent can:
- access only linked student
- use invitation + verification
- revoke access

Never expose:
internal notes
staff KPI
commission
other students
audit logs
unrelated internal data

Add student-facing notification center.
